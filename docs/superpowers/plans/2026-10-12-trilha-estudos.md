# Trilha de Estudos Gamificada Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a gamified study path ("trilha") where a student reads a topic's content, watches a video, and takes a 10-question quiz, needing 70%+ correct to be marked "aprovado" for that topic.

**Architecture:** Topics and the question→topic mapping are static JSON files (like `questoes.json`/`redacoes.json` already are), curated by hand. A new Postgres table `trilha_progresso` tracks per-user, per-topic status/best score/attempt count. Three new Express endpoints expose the topic list (merged with progress), a randomized quiz draw, and quiz submission/scoring. The frontend adds a trail list page and a topic page with three local states (content → quiz → result), reusing the existing `QuestionCard` component unchanged.

**Tech Stack:** Express 4, Drizzle ORM (`drizzle-orm/node-postgres`), Postgres, React 18 + Vite + Tailwind, `react-router-dom`.

**Spec:** `docs/superpowers/specs/2026-10-12-trilha-estudos-design.md`

## Global Constraints

- No XP, levels, streaks, or badges — only a per-topic status (`nao_iniciado | reprovado | aprovado`). No sequential locking of topics.
- Topic content and video URL are static data, curated by hand — no AI content generation at runtime.
- The trilha quiz has no timer (unlike `/app/simulado`).
- Approval rule: `acertos / total >= 0.7` (70%), not a hardcoded "7 of exactly 10" — this matters when a topic's question pool has fewer than 10 questions.
- Each quiz attempt draws a fresh random sample from the topic's question pool.
- Approval status never regresses: once `'aprovado'`, a later worse attempt keeps the status `'aprovado'` (but `tentativas` still increments and `melhorAcertos` only updates upward).
- `GET /trilha/topicos/:id/quiz` must never include the `correta` field in its response.
- `GET /trilha/topicos` is a single, unpaginated endpoint — topic count is small (tens, not thousands).
- `backend/data/questoes-topicos.json` stays separate from `backend/data/questoes.json` (the latter is regenerated by `npm run extract` and would wipe manual topic tagging).
- Node >=18, Postgres via Drizzle ORM (already set up in `backend/src/db.js` and `backend/src/schema.js`).
- Local dev Postgres runs via `docker compose up -d` from the repo root (`Fatec/docker-compose.yml`); `backend/.env` already has `DATABASE_URL` pointing at it.

- [ ] **Step 1: Create the route file**

```js
import { Router } from 'express';
import { eq } from 'drizzle-orm';
import { db } from '../db.js';
import { trilhaProgresso } from '../schema.js';
import { requireAuth } from '../middleware/auth.js';
import { asyncHandler } from '../middleware/asyncHandler.js';
import { topicos } from '../data.js';

export const router = Router();

router.get(
  '/trilha/topicos',
  requireAuth,
  asyncHandler(async (req, res) => {
    const progresso = await db.select().from(trilhaProgresso).where(eq(trilhaProgresso.userId, req.user.id));
    const progressoPorTopico = new Map(progresso.map((p) => [p.topicoId, p]));

    const resultado = topicos.map((t) => {
      const p = progressoPorTopico.get(t.id);
      return {
        ...t,
        status: p?.status ?? 'nao_iniciado',
        melhorAcertos: p?.melhorAcertos ?? null,
        tentativas: p?.tentativas ?? 0,
      };
    });

    res.json(resultado);
  })
);
```

```js
function sortear(lista, n) {
  const copia = [...lista];
  for (let i = copia.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copia[i], copia[j]] = [copia[j], copia[i]];
  }
  return copia.slice(0, n);
}

router.get(

    const semGabarito = sorteadas.map(({ correta, ...resto }) => resto);
    res.json(semGabarito);
  })
```

**Files:**

Then add this route after the `GET /trilha/topicos/:id/quiz` route:

```js
router.post(
  '/trilha/topicos/:id/quiz',
  requireAuth,
  asyncHandler(async (req, res) => {
    const topicoId = req.params.id;
    const enviadas = req.body?.respostas;
    if (!enviadas || typeof enviadas !== 'object' || Array.isArray(enviadas)) {
      return res.status(400).json({ erro: 'Envie o campo respostas' });
    }

    const entradas = Object.entries(enviadas).filter(
      ([questaoId]) => questoesById.get(questaoId)?.topico === topicoId
    );
    if (entradas.length === 0) {
      return res.status(400).json({ erro: 'Nenhuma resposta válida para este tópico' });
    }

    const questoesCorrigidas = [];
    let acertos = 0;
    for (const [questaoId, resposta] of entradas) {
      const questao = questoesById.get(questaoId);
      const correta = questao.anulada ? true : resposta === questao.correta;
      if (correta) acertos++;
      await db.insert(respostas).values({
        userId: req.user.id,
        questaoId,
        resposta,
        correta,
        modo: 'trilha',
      });
      questoesCorrigidas.push(questao);
    }

    const total = entradas.length;
    const aprovadoNestaTentativa = acertos / total >= 0.7;

    const [existente] = await db
      .select()
      .from(trilhaProgresso)
      .where(and(eq(trilhaProgresso.userId, req.user.id), eq(trilhaProgresso.topicoId, topicoId)));

    const aprovado = aprovadoNestaTentativa || existente?.status === 'aprovado';
    const melhorAcertos = Math.max(acertos, existente?.melhorAcertos ?? 0);
    const tentativas = (existente?.tentativas ?? 0) + 1;
    const status = aprovado ? 'aprovado' : 'reprovado';

    await db
      .insert(trilhaProgresso)
      .values({ userId: req.user.id, topicoId, status, melhorAcertos, tentativas })
      .onConflictDoUpdate({
        target: [trilhaProgresso.userId, trilhaProgresso.topicoId],
        set: { status, melhorAcertos, tentativas, atualizadoEm: sql`now()` },
      });

    res.json({ acertos, total, aprovado, melhorAcertos, tentativas, questoes: questoesCorrigidas });
  })
);
```

```jsx
import { useEffect, useState } from 'react';
import { Link } from 'react-router-dom';
import { api } from '../api/client.js';

const STATUS_STYLE = {
  nao_iniciado: 'bg-slate-300 dark:bg-slate-700 text-slate-700 dark:text-slate-200',
  reprovado: 'bg-amber-400 text-amber-950',
  aprovado: 'bg-green-500 text-white',
};

const STATUS_LABEL = {
  nao_iniciado: 'Não iniciado',
  reprovado: 'Reprovado — tente de novo',
  aprovado: 'Aprovado',
};

export default function Trilha() {
  const [topicos, setTopicos] = useState(null);
  const [erro, setErro] = useState('');

  useEffect(() => {
    api.getTrilha().then(setTopicos).catch((e) => setErro(e.message));
  }, []);

  if (erro) return <p className="text-sm text-red-600">{erro}</p>;
  if (!topicos) return <p className="text-slate-500">Carregando...</p>;

  for (const t of topicos) {
    if (!porMateria.has(t.materia)) porMateria.set(t.materia, []);
    porMateria.get(t.materia).push(t);
  }
  for (const lista of porMateria.values()) lista.sort((a, b) => a.ordem - b.ordem);

  return (
    <div className="space-y-6">
      <h1 className="text-xl font-bold">Trilha de estudos</h1>
      {[...porMateria.entries()].map(([materia, lista]) => (
        <div key={materia} className="rounded-xl border border-slate-200 dark:border-slate-800 bg-white dark:bg-slate-900 p-5">
          <h2 className="font-bold mb-3">{materia}</h2>
          <div className="flex flex-wrap gap-3">
            {lista.map((t) => (
              <Link
                key={t.id}
                to={`/app/trilha/${t.id}`}
                className="flex flex-col items-center gap-1.5 w-24 text-center group"
              >
                <span
                  className={`w-12 h-12 rounded-full flex items-center justify-center font-bold text-sm ${STATUS_STYLE[t.status]} group-hover:opacity-80`}
                  title={STATUS_LABEL[t.status]}
                >
                  {t.status === 'aprovado' ? '✓' : t.ordem}
                </span>
                <span className="text-xs text-slate-600 dark:text-slate-400">{t.nome}</span>
              </Link>
            ))}
          </div>
        </div>
      ))}
    </div>
  );
}
```

```jsx
import { useEffect, useState } from 'react';
import { useParams, useNavigate, Link } from 'react-router-dom';
import { api } from '../api/client.js';

export default function Topico() {
  const { id } = useParams();
  const navigate = useNavigate();
  const [topico, setTopico] = useState(null);
  const [temQuestoes, setTemQuestoes] = useState(null);
  const [fase, setFase] = useState('conteudo'); // conteudo | quiz | resultado
  const [erro, setErro] = useState('');

  useEffect(() => {
    api
      .getTrilha()
      .then((lista) => {
        const encontrado = lista.find((t) => t.id === id);
        if (!encontrado) {
          setErro('Tópico não encontrado');
          return;
        }
        setTopico(encontrado);
      })
      .catch((e) => setErro(e.message));
  }, [id]);

  useEffect(() => {
    api
      .getQuizTopico(id)
      .then(() => setTemQuestoes(true))
      .catch(() => setTemQuestoes(false));
  }, [id]);

  if (erro) return <p className="text-sm text-red-600">{erro}</p>;
  if (!topico) return <p className="text-slate-500">Carregando...</p>;

  if (fase === 'conteudo') {
    return (
      <div className="space-y-6">
        <Link to="/app/trilha" className="text-sm text-blue-600">
          ← Voltar pra trilha
        </Link>
        <div className="rounded-xl border border-slate-200 dark:border-slate-800 bg-white dark:bg-slate-900 p-6 space-y-4">
          <span className="text-xs text-slate-500 dark:text-slate-400">{topico.materia}</span>
          <h1 className="text-xl font-bold">{topico.nome}</h1>
          <p className="whitespace-pre-line leading-relaxed text-slate-700 dark:text-slate-300">{topico.conteudo}</p>
          <div className="aspect-video rounded-lg overflow-hidden border border-slate-200 dark:border-slate-700">
            <iframe
              src={topico.videoUrl}
              title={topico.nome}
              className="w-full h-full"
              allowFullScreen
            />
          </div>
          {temQuestoes === false && (
            <p className="text-sm px-3 py-2 rounded-md bg-amber-100 text-amber-800 dark:bg-amber-900/30 dark:text-amber-300">
              Ainda não há questões cadastradas para este tópico — volte em breve.
            </p>
          )}
          <button
            onClick={() => setFase('quiz')}
            disabled={!temQuestoes}
            className="w-full py-2.5 rounded-lg bg-blue-600 text-white font-semibold hover:bg-blue-700 disabled:opacity-60"
          >
            Fazer quiz
          </button>
        </div>
      </div>
    );
  }

  return null;
}
```
